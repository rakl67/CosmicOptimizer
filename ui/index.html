Контроль телеметрии на компьютере

Считываю политики Windows и приложений…

— ограничений активно
Профиль активирует доступные ограничения Windows, разрешений приложений, задач совместимости и CEIP, Microsoft Office, Edge, .NET CLI, PowerShell, Chrome и Firefox. Он также останавливает и отключает службу диагностики DiagTrack; исходные состояния задач и службы сохраняются для отката. Ограничения доступа приложений к камере, микрофону, местоположению и файлам могут повлиять на их работу. Необязательная телеметрия ограничивается, но обязательные данные безопасности на обычных редакциях Windows полностью не отключаются. Defender и Windows Update остаются включены.
Перед изменением сохраняется точное исходное значение. После активации перезапустите браузеры и приложения Office; для переменных .NET CLI и PowerShell перезапустите Проводник, войдите в Windows заново или откройте новый терминал.
Список видеокарт Windows. Перед изменением сохраняется список устройств. Отключение видеокарты может погасить экран — если это единственная видеокарта, потребуется второй экран или удалённый доступ.

Перенести настройки на другой компьютер

            

              
Экспортируйте состояние настроек каталога Cosmic Optimizer в один файл .cosmicprofile и отправьте его другу. При импорте приложение покажет, что включит и выключит, пропустит AMD/NVIDIA пункты для неподходящей видеокарты и сохранит бэкап компьютера перед изменениями. Скрипты, настройки вне каталога приложения и схема питания в профиль не входят.
