Cosmic Optimizer объединяет мониторинг компьютера, настройку Windows и обслуживание системы в одном окне.

## Последняя версия: 1.0.3

- Добавлена иконка Cosmic Optimizer на странице проекта.
- Обновлены splash screen и стартовый экран приложения.
- Улучшен запуск окна: приложение больше не закрепляется поверх других окон после запуска.
- Кнопка «Скачать для Windows» всегда ведёт на актуальный опубликованный релиз.

## Что внутри

- **Мониторинг:** загрузка процессора, памяти и видеокарты, графики и доступная температура GPU.
- **Оптимизация Windows:** настройки реестра, конфиденциальности и схемы электропитания.
- **Обслуживание:** безопасная очистка выбранных временных данных, сведения о дисках и короткий тест накопителя.
- **Инструменты:** диагностика, скрипты, резервные копии и переносимые профили настроек.

## Как начать

1. Нажмите **«Скачать для Windows»** — загрузится последняя сборка.
2. Запустите `CosmicOptimizer.exe`.
3. Выберите нужный раздел. Для некоторых системных действий Windows попросит права администратора.

В приложении можно посмотреть описание действия до запуска. Для поддерживаемых настроек доступны резервная копия и откат; перед очисткой выбираются конкретные категории файлов.

## О проекте

Cosmic Optimizer — настольное приложение для Windows 10 и 11. Сеть используется только для выбранных пользователем действий, например открытия ссылки или загрузки инструмента. Заметки об изменениях и новые сборки — на странице [релизов](https://github.com/rakl67/CosmicOptimizer/releases).
