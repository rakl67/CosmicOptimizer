# Cosmic Optimizer

**Версия:** v1.0.2 · **Создатель:** rakl679

Cosmic Optimizer помогает проверить состояние компьютера и управлять настройками Windows из одного окна.

Настольное приложение для диагностики и настройки Windows 10/11. Интерфейс работает на HTML, CSS и JavaScript, системные операции — на Python через pywebview.

## Возможности

- Мониторинг системы и поиск по настройкам.
- Настройки реестра с просмотром состояния и откатом.
- Скрипты с описанием рисков и резервированием реестра перед импортом `.reg`.
- Резервные копии и перенос профиля настроек между компьютерами с проверкой видеокарты.
- Очистка выбранных временных файлов, сведения о дисках и короткий тест накопителя.
- Раздел телеметрии с кнопкой «Активировать все»: ограничения Windows, разрешений приложений, задач совместимости и CEIP, службы DiagTrack, а также диагностики Microsoft Office, Edge, .NET CLI, PowerShell, Chrome и Firefox. Исходные состояния задач и службы, а также точные значения реестра сохраняются для восстановления.

Действия, которые меняют Windows, запускаются только по выбору пользователя. Некоторые встроенные скрипты меняют системные параметры и помечены предупреждениями. Перед запуском прочитайте описание на карточке.

## Требования

- Windows 10 или 11, 64-разрядная версия.
- Python 3.11 или новее.
- WebView2 Runtime.

Установите зависимости и запустите приложение:

```powershell
python -m pip install -r requirements.txt
python main.py
```

Для запуска через файл используйте `run.bat`.

## Сборка EXE

Сборка одним файлом:

```powershell
python -m PyInstaller --clean --noconfirm build_onefile.spec
```

Готовый файл появится в `dist/CosmicOptimizer.exe`. Для сборки папочной версии используйте `build.spec`; передавать нужно всю папку `dist/CosmicOptimizer`.

Интерфейс и материалы скриптов включаются в сборку. Встроенные `.reg`-файлы приложение не импортирует, если не может создать полный бэкап или безопасно обработать формат.

## Файлы проекта

```text
backend/       работа с Windows и логика приложения
ui/            интерфейс
scripts/       скрипты и материалы, доступные в приложении
assets/        встроенные файлы для инструментов
main.py        запуск окна и API интерфейса
app.manifest   запрос прав администратора для EXE
build*.spec    настройки PyInstaller
```

Логи, бэкапы и настройки пользователя хранятся в `%LOCALAPPDATA%\CosmicOptimizer`.

## Примечания

Изменение параметров Windows может повлиять на работу системы. Перед применением настроек и импортом профиля создайте резервную копию. Переносимый профиль содержит только состояния настроек, предусмотренных приложением; он не является образом системы.

Сеть используется по запросу пользователя — например, при скачивании инструмента или проверке ping. Фоновая телеметрия не используется.

Раздел «Телеметрия» меняет документированные политики Windows и поддерживаемых приложений. Профиль может остановить службу DiagTrack и отключить доступ приложений к камере, микрофону, местоположению и файлам; эти функции станут недоступны до отката. Он также может отключить доступные системные задания совместимости и CEIP. Windows Update и Microsoft Defender не отключаются. Доступный уровень зависит от редакции Windows: обязательные данные на Home/Pro полностью отключить нельзя. Политики Chrome и Firefox появляются, только если браузер обнаружен.
