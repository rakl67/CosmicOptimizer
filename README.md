# Cosmic Optimizer

Cosmic Optimizer помогает проверить состояние компьютера и управлять настройками Windows из одного окна.

Настольная программа для диагностики и настройки Windows 10/11. Здесь собраны мониторинг системы, управление настройками Windows, обслуживание компьютера и инструменты для игр.

## Возможности

- Мониторинг системы и поиск по настройкам.
- Управление настройками реестра и схемами электропитания с возможностью отката.
- Телеметрия и параметры конфиденциальности Windows и поддерживаемых приложений.
- Очистка временных файлов, обслуживание дисков и тест скорости накопителя.
- Мониторинг CPU, памяти, видеокарты и температур, если датчики доступны.
- Скрипты, системные инструменты, резервные копии и перенос профилей.

Системные действия запускаются только по выбору пользователя. Перед применением настроек можно ознакомиться с описанием и подтверждением; для поддерживаемых действий сохраняются исходные значения.

Скачать актуальную сборку Windows можно во вкладке **Releases**. Подробности обновлений публикуются в заметках к соответствующему релизу.
